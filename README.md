## Ep.6-คืนที่โลกไม่อาจรับไหว

ไรน์ผ่านมามากกว่า 99 จักรวาล
ในบางแห่ง เขากับบอสเป็นศัตรู
ในบางแห่ง เขากับบอสเป็นคู่รัก
และในบางแห่ง… พวกเขาไม่เคยเจอกันเลย

แต่ไม่มีสักโลกที่ *เหมือนวันแรกที่เขาฆ่าบอสไป*

จนกระทั่ง… เขากลับมาถึง “โลกที่ 0”
โลกที่เขาทำลายด้วยมือของตัวเอง

เขากลับมายืนที่เดิม—หน้าหลุมศพนั้น
แต่ครั้งนี้ เขาแบกพลังของ “น้องๆ” ทั้งหมดไว้ในมือเดียว
เขาจะ "ฉีกกฎแห่งความจริง" ให้แหลกละเอียด

“โลกนี้ไม่ได้ถูกสร้างขึ้นเพื่อให้ย้อนกลับไป
งั้นฉันก็จะสร้างโลกใหม่ ที่บอสมีชีวิต
และฉันจะไม่มีวันทำร้ายเขาอีก…”



## ตอนจบ — Ep.6-บทสุดท้ายของหมาจิ้งจอกไร้เจ้าของ

ไรน์กระแทกพลังของน้องๆลงกลางใจโลก
เส้นทางทั้ง 100 จักรวาลรวมกัน—สร้าง “โลกที่ n” ขึ้นมา
ไม่ใช่การย้อนอดีต
แต่คือโลกที่เลือก "ความรัก" แทน "ความเข้าใจผิด"

---

เช้าวันใหม่
ไรน์ลืมตาขึ้นบนเตียงไม้หลังเก่า
ข้างๆ มีชายหนุ่มคนหนึ่งกำลังนอนหลับอยู่ โดยมีแขนพาดมาคล้องเอวเขาไว้

เสียงหายใจสม่ำเสมอและกลิ่นเสื้อเชิ้ตคุ้นเคยทำให้เขากลั้นน้ำตาไม่ไหว

“บอส... บอสของฉัน…”

ชายคนนั้นขยับตัวเล็กน้อยก่อนพูดงัวเงีย

“หมาน้อย... ร้องไห้ทำไมแต่เช้า?”

ไรน์ยิ้มทั้งน้ำตา โผเข้ากอดเขาแน่น

“ไม่มีอะไรครับ... แค่... ฝันร้าย”
